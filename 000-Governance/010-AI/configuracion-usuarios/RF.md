# RF — Requisitos funcionales — configuracion-usuarios

| ID | Requisito | Prioridad | Estado |
|---|---|---|---|
| RF-USR-001 | La lista de usuarios debe mostrar la última vez que cada cuenta inició sesión (o "Nunca inició sesión" si no hay registro). | Alto | Construido y verificado |
| RF-USR-002 | El sistema debe alertar visualmente (badge + banner resumen) cuando una cuenta activa lleva más de 90 días sin conectarse, o nunca se conectó y ya lleva más de 90 días creada. | Alto | Construido y verificado |

## Notas
- Origen: continuación de "GRC formal" tras acotar BI/GRC — la parte de GRC identificada como valiosa sin sobre-ingeniería fue "revisión periódica de accesos", no un framework de auditoría/SoD completo.
