# Cruce RF genérico → XXOil: BI (Business Intelligence)

**Fuente:** `Requerimientos_Funcionales_SAP_BI.md` (53 RF). **Resultado:** 0 Obligatorio hoy, 6 ya cubiertos de forma reducida (analítica embebida básica), 47 Fase futura (M7).

XXOil no necesita un data warehouse (BW), una plataforma SaaS de planificación colaborativa (SAC) ni reporting empresarial pixel-perfect (BusinessObjects) — todo su volumen de datos transaccionales cabe cómodo en consultas directas sobre la base operativa, que es exactamente lo que ya se construyó: un hub de "Reportes" (`/reportes`) con dashboards ejecutivos por módulo, gráficas (tendencia de ventas, top clientes) y reportes específicos (costos y márgenes, rentabilidad por segmento, situación financiera). Esto es, en esencia, **RF-BI-001 a 005 (Analítica Embebida) ya resuelto a mano**, sin necesitar CDS Views ni un motor BI separado.
