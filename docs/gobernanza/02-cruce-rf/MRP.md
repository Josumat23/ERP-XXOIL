# Cruce RF genérico → XXOil: MRP (Planificación de Necesidades de Material)

**Fuente:** `Requerimientos_Funcionales_SAP_MRP.md` (44 RF) + secciones MRP de `SAP_MM.md` (RF-MM-058 a 063) y `SAP_PP.md` (RF-PP-013 a 020), consolidadas aquí para no duplicar IDs (tal como recomiendan las notas finales de esos dos documentos). **Resultado:** 6 Obligatorio (todos ya construidos), 5 Deseable, 33 No aplica (M1).

**Corrección post-diagnóstico (verificado en código antes de programar nada):** la primera versión de este documento marcaba RF-MRP-025 a 029 como "gap menor real" asumiendo que el MRP podía sobre-sugerir compra al no distinguir stock pendiente de control de calidad. Se verificó `resolverInspeccionCompra` (`src/app/(app)/logistica/inspeccion-compras/actions.ts`): `registrarMovimiento()` solo se ejecuta dentro de la rama `resultado === "APROBADO"` — mientras la inspección está pendiente, `insumo.stock` nunca se incrementa. El MRP, que lee `insumo.stock` directo, ya excluye automáticamente lo pendiente de calidad por el propio diseño del choke-point de inventario. No había gap; se corrige la fila abajo.

XXOil ya tiene MRP funcional (`/logistica/mrp`), pero bajo un modelo **determinístico simple**, no el motor configurable de SAP: explota la demanda de una `Proyeccion` (trimestral) contra las fórmulas de producción (`Formula`/`FormulaDetalle`) para calcular necesidad neta de insumos, y agrupa lo faltante por proveedor para sugerir una orden de compra con un clic. No hay tipos de MRP configurables por material (punto de pedido vs. determinístico vs. consumo), ni ejecución batch programada, ni MRP Live — y **no hacen falta** para una sola planta con un catálogo de fórmulas manejable.
