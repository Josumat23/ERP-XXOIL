# Cruce RF genérico → XXOil: HCM (Human Capital Management)

**Fuente:** `Requerimientos_Funcionales_SAP_HCM.md` (63 RF). **Resultado:** 6 Obligatorio (3 ya hechos, 3 gap real crítico: nómina), 5 Deseable, 52 No aplica/Fase futura.

Regla de filtrado del usuario: solo datos de empleado, vacaciones, comisiones y nómina básica — nada de reclutamiento, desarrollo de carrera ni gestión de eventos. Verificado: `Empleado`+`SolicitudVacaciones` ya cubren PA (Administración de Personal) y una parte de PT (Gestión de Tiempos, solo vacaciones). El gap real y crítico es **Nómina (PY)**: no existe ningún cálculo de planilla, aportes ni integración contable de sueldos — es, junto con el registro actual en Excel/cuaderno, una de las razones de ser del proyecto. Se marca **Obligatorio para dejar de usar Excel**, no fase futura.
